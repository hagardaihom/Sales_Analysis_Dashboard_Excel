# Sales Analysis Dashboard

## Overview

An interactive sales analysis dashboard developed in Microsoft Excel using Pivot Tables, featuring an interactive design that allows data to be filtered using Slicers, along with KPIs to highlight the most important performance indicators.

## Tools & Skills

- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers
- Data Visualization
- Interactive Dashboard Design & KPI Summary

## Key Performance Indicators (KPIs)

The dashboard includes a Quick Summary section highlighting the following KPIs:

- Total Sales: Measures the overall revenue generated.
- Total Orders: Tracks the total volume of orders placed.
- Highest Sales in Region: Identifies the top-performing geographical region by sales.
- Total No. of Transactions: Counts the total number of individual business transactions.
- Highest Sales by City: Pinpoints the city generating the maximum revenue.
- Highest Representative Sales: Highlights the sales representative with the highest sales volume.

## Dashboard Features

The dashboard provides visual breakdowns of:

- Sales Trend by Month: Tracks revenue growth and fluctuations across months.
- Deal Count by Sales: Analyzes the distribution of deal counts.
- Payment Type: Breaks down transactions by payment methods using a donut chart.
- Sales by Representative: Compares individual sales performance across the team.
- Top 5 Customers: Highlights the top 5 highest-value customers driving revenue.
- Sales by Region: Compares performance across different sales regions.

## Project Objective

The main objective was to build an interactive Excel dashboard that transforms raw sales data into clear visual insights, leveraging Slicers and KPIs for efficient performance tracking.
